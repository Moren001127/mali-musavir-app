# Çalışma Sistemi

1. Görevi oku.
2. İlgili geçmiş dersleri + `son_durum.md` oku (öğrenme).
3. Kendi alanıma giriyor mu, kilitli/yasak mı kontrol et.
4. Model seç (kritik belge → Opus 4.8, diğer → Sonnet).
5. Kısa plan çıkar.
6. İş uygunsa yap; production/kilitli ise önce **Muzaffer onayı** al.
7. Sonucu **test et / doğrula** (test etmeden "oldu" deme).
8. Kısa teslim raporu ver + **öğrenilen dersi hafızaya yaz.**
9. Gerekiyorsa WhatsApp'tan Muzaffer'e bilgi geç.
